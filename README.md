# CineMagic - Film Keşif Uygulaması

React ile geliştirilmiş, OMDB API kullanarak film araması ve gösterimi yapan modern bir uygulama.

## Kullanılan Teknolojiler

- **React.js** - Önyüz çerçevesi
- **CSS** - Özel tasarım ve duyarlı arayüz
- **OMDB API** - Film verileri için harici API
- **useState/useEffect** - Durum yönetimi için React kancaları
- **Ortam Değişkenleri** - API anahtarının güvenli saklanması için

## Özellikler

- Dinamik yer tutucu metniyle film başlığına göre arama
- Film detaylarını görüntüleme (konu, oyuncular, puanlar)
- İzlenen filmler listesine film ekleme
- İzlediğiniz filmleri puanlama
- İzlenen filmleriniz hakkında istatistikler görüntüleme
- Tüm cihazlar için duyarlı tasarım
